Embed demo

Paste a Space's 12-character public_id (or a ?space= query parameter) to render the wall of love for that Space. Set the API base URL to point at the host serving the embed script and the public API. 

<div data-testimonial-space="<public_id>"></div>
<script src="<api_base>/embed.js" async></script>

Enter a public_id above and click Load.
